# Stream visual assets

This folder contains the bundled avatar, frame, and intermission artwork used by StreamKit.

Main groups:

- `MyAvatar/` — simple talking-avatar PNGs.
- `Frames/` — horizontal and vertical stream overlays.
- `Screens/` — Starting Soon / BRB artwork.
- `Themes/` — themed visual profiles and their assets.

The release build may regenerate active frame/intermission art so horizontal and vertical layouts stay consistent.

These are visual assets only. Never add OBS `service.json`, Twitch/TikTok stream keys, cookies, login tokens, or other local account data to this folder or repository.
