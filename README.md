# Portable Stream Kit

Portable Windows launcher for game capture, Discord sharing, optional VTuber avatars and OBS streaming.

[Download latest ZIP](https://github.com/Zudin987/BPSR-Portable-Stream-Kit/releases/latest) · [Project website](https://zudin987.github.io/projects/streamkit/) · [Report an issue](https://github.com/Zudin987/BPSR-Portable-Stream-Kit/issues)

## Start a capture or stream

Use the **64-bit Windows** release. Extract the **whole ZIP** and keep its OBS/plugin bundle together.

1. Open your game.
2. Run `BPSRStreamKit.exe` from the extracted folder.
3. Choose the game, avatar, frame and destination.
4. Press the main start button.
5. Use **Quick Launch** next time to reuse your last setup.

## Choose a destination

| Destination | What you need to do |
| --- | --- |
| Discord | Share the OBS **Program Projector** window |
| Twitch | Connect your account in OBS |
| TikTok | Use an account that already has LIVE/stream-key access |

Avatars are optional: use a simple talking PNG, connect Live2D through VTube Studio, or select none. **VTube Studio is not bundled.**

## Troubleshooting and updates

- If files or plugins are missing, extract the complete release ZIP again. Do not move only the launcher EXE.
- Check the selected game and destination if the expected capture is not visible.
- Keep the portable OBS/plugin bundle together and update it through a newer Stream Kit release.
- For a bug report, include the app version, selected game, destination and steps to reproduce it. Do not include stream keys.
