# Portable Stream Kit

Portable Windows launcher for game capture, Discord sharing, VTuber avatars, Twitch, and optional TikTok streaming.

**Website:** https://zudin987.github.io/projects/streamkit/

## Use

1. Download the latest ZIP from [Releases](https://github.com/Zudin987/BPSR-Portable-Stream-Kit/releases/latest).
2. **Extract the whole ZIP.**
3. Open your game.
4. Run `BPSRStreamKit.exe`.
5. Choose the game, avatar, frame, and destination.
6. Press the main start button.

Use **Quick Launch** next time to reuse your last setup.

- Discord: share the OBS Program Projector window.
- Twitch: connect your account in OBS.
- TikTok: optional; your account must already have LIVE/stream-key access.
- Avatar: Live2D/VTube Studio, simple talking PNG, or none.

VTube Studio is not bundled. Keep the portable OBS/plugin bundle together and update it through a newer StreamKit release.
