# Asset-inclusive build validation

This branch exists to verify that the Windows launcher still publishes successfully after bundling the final stream visual assets.

Validated asset groups:
- FloodTuber avatar states
- Horizontal stream frames
- TikTok vertical frame
- Horizontal Starting / BRB screens
- Vertical Starting / BRB screens

No account credentials, service.json files, stream keys, cookies, or local OBS user data are included in these assets.
